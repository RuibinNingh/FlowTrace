# 账本、分类与标签管理

职责：编辑当前资料空间的账本设置、两级分类、标签和分组，以真实本地事务生成待同步命令。
入口：`apps/flowtrace/lib/features/management/management_page.dart`；编辑器与模板位于同目录，由首页抽屉和记账编辑器打开。
不变量：不写样例假数据；显示模型与完整可编辑模型分开；换身份立即隐藏旧表单且旧页不复活；配置复制不包含资金账户、流水或成员。
必跑测试：客户端 `flutter --no-version-check test --no-pub test/management`、`flutter --no-version-check analyze --no-pub lib/features/management test/management`；跨模块改动补整合回归和真实 Android 主路径。
相关材料：[本地账务](ledger-data.md)、[记账界面](entry.md)、[客户端](client.md)、[管理契约](../../contracts/management-v1.md)、[产品页面范围](../plans/flowtrace/product-scope.md)。

## 当前行为

`ManagementPage` 接受 `LedgerRepository`、固定 `DataSpace`、`initialBookId`、`isCurrent`、可选 `sessionChanges` 和 `onBookSelected`。三个标签页共用 `watch(includeArchived:true)` 的一致视图，不另建数据库或网络通道。账本选择通过回调交还首页；尚未登录的 provisional 空间不以此页面产生正式账本。

账本可新建、修改名称/图标/封面色/币种/IANA 时区/月起始日，设置资产入口和 month/year/all 显示方式。币种限两端既定目录，已经产生流水的币种约束由账务验证器裁决。已有配置可复制到新账本，名称需显式填写；复制只接受账本设置、分类、组和标签白名单，重新生成 UUID 并映射父子引用，不复制账户、流水、余额、预算、成员或附件。

模板提供空白及已观察到的九种用途：日常、旅行、装修、婚礼、人情、出差、公司、生意、车辆。页面明确其中预置分类为 FlowTrace 默认；当前证据不包含原应用各模板的全部私有初始内容，不将这些默认项称作逐项复刻。创建模板时按账本→一级分类→二级分类顺序单次 `saveBatch`，本机全部提交或回滚；远端仍按每项操作处理。

分类支持收支分别维护、单项/批量新增、名称/语义图标编辑、图标检索、同级排序、一级与二级转换、归档/恢复和删除。存在子项时禁止把父分类变为二级或改为另一收支类型；历史引用等约束由账务层校验，错误时保留表单输入。批量名称每行一项，最多 100 项，并检查空白、长度和批内重复。

标签支持单项和分组、颜色、组内/未分组切换、同级排序、归档/恢复和删除。父分类或组归档使子项有效归档，但不覆写子项自己的 archived 标志；恢复父项也不会复活原本已单独归档的子项。删除带引用定义被验证器拒绝，不绕过限制清除历史引用。

编辑前与提交前均检查资料空间和当前授权。owner 可改账本设置，editor 可维护该账本的分类/标签，viewer 明示只读；恢复/冲突导致的只读也禁止正式写入。页面只使用 `editablePayload` 允许的完整内容，不将受限投影补空保存。身份通知到来时旧表单隐藏；一旦失效便保持失效，即使同账号再次登录也须重新进入页面。

## 已执行验证

管理目录静态分析无问题，`test/management` **8/8 通过**。实际使用隔离 Native SQLite 和 `LedgerRepository` 验证模板事务/依赖、复制后 UUID 重映射且账户不复制、分类批量/图标/层级/排序/归档、标签组归档继承/移动/删除、空账本角色、身份切换及同账号返回后旧输入不复活、失败后输入保留和显式重试。

首轮测试在自动销毁 Drift 观察流后留下零时计时器，随后 fakeAsync 中关闭库等待；测试改为显式卸载、pump/drain、在 runAsync 关闭库后通过。另有归档用例误定位 `TabBarView` 邻页的同名筛选，改为当前分类页的稳定控件标识并重跑，不以关闭诊断或改变账务行为解决测试。

同一授权 PLT140（Android16/API36/arm64）上 `integration_test/ledger_test.dart` **1/1 通过**：实际页面创建账本并打开资产入口、支出父子分类、收入分类、标签和两个资金账户，再录入三笔业务。优惠、手续费和独立标记、精确余额、受控断网下磁盘重开及第二会话 HTTP 核对见[客户端](client.md)。此轮原生证明上述新增主路径；其他编辑/复制/归档/权限交互仍以隔离 widget 和服务端测试为证，不能宣称每项都已完成真机对照。

首次原生用例在切换收入分类时由测试 helper 的 ensureVisible 引起横向 TabBarView 滚动；只对不可点控件滚动、并明确等待保存路由退出后，第二轮完整通过。未改业务行为或用固定坐标绕过页面。设备内生成截图未在 Flutter 工具自动卸载测试包前导出，当前没有该张主路径截图；不把 P2 历史截图补作 P3 证据。
