# 流迹后台页面系统

服务管理员在笔记本/手机近距离操作；低动效、高信息可读性、低装饰依赖。沿用Flutter客户端的蓝色方向，使用“流迹 / FLOWTRACE”文字身份；计数与状态来自实际服务。

主色 #2279d7、文字/侧栏 #192b45、中性 #65748a、画布 #f2f3f6；品牌线 #3593fd、焦点 #7ea3fa。8px 间距基线；控件圆角8px、面板10px；系统字体确保离线部署可用；正文16px、表格13px、标题32px；44px操作触点。仅登录卡片有轻阴影；状态同时提供文字，150ms交互过渡遵循reduced-motion；700px以下导航横排、指标单列，长表格仅在自身容器内横滚。

视图角色：登录专注身份输入；概览展示真实服务计数；用户/会话/邀请/审计为列表管理。不增加指标趋势、营销图或未实现管理功能的按钮。

验收基线为390×844和1280×800；检查中文层级、键盘焦点、真实空态/错误态、表单和确认步骤，以及根页面是否横向溢出。具体浏览器执行结果记在当前开发任务日志，样式文件存在不代表已通过验收。
